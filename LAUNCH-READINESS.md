# AYÉRA — Launch readiness status

## Status
This project is currently a demo/static front-end prototype. It is not a production-ready platform for live users, accounts, listings, or community content.

## Conditions for launch
- real security contact listed and active
- validated CSP and security headers
- compliant tile provider or valid API key
- SRI enforced for all third-party scripts
- fake live-user or multiplayer claims removed
- privacy policy and terms added
- real-device QA completed
- demo/editorial content clearly labeled

## Current state
- Front-end prototype: ready for preview
- Public production launch: not yet approved
